# 🧛 Vampire Vibe

뱀파이어 서바이버 스타일의 웹 기반 생존 게임입니다. 끝없이 몰려오는 적들을 물리치고 최대한 오래 생존하세요!

## 🎮 게임 방법

### 조작법
- **WASD** 또는 **방향키**: 플레이어 이동
- 무기는 자동으로 공격합니다

### 목표
- 적들을 처치하고 경험치를 획득하세요
- 레벨업 시 다양한 무기와 아이템 중 선택하세요
- 최대한 오래 생존하세요!

## 🎯 게임 실행

### 방법 1: 직접 실행
`index.html` 파일을 웹 브라우저에서 열기

### 방법 2: 로컬 서버 실행
```bash
# Python 3 사용
python3 -m http.server 8000

# 또는 Node.js 사용
npx http-server
```

그 다음 브라우저에서 `http://localhost:8000` 접속

## ⚔️ 무기 목록

### 마법 미사일 🔮
- 시작 무기
- 가장 가까운 적을 자동 추적
- 업그레이드: 발사체 수 증가, 공격 속도 증가

### 화염구 🔥
- 폭발 범위 공격
- 적중 시 주변 적들에게 추가 피해
- 업그레이드: 폭발 범위 증가, 쿨다운 감소

### 번개 ⚡
- 연쇄 타격 공격
- 여러 적을 순차적으로 타격
- 업그레이드: 연쇄 횟수 증가

### 성수 💧
- 지면에 데미지 구역 생성
- 구역 내 적들에게 지속 피해
- 업그레이드: 범위 및 지속시간 증가

### 마늘 오라 🧄
- 플레이어 주변 방어 오라
- 근접한 적들에게 지속 피해
- 업그레이드: 범위 증가

### 부메랑 🪃
- 되돌아오는 투사체
- 왕복 경로의 모든 적 타격
- 업그레이드: 부메랑 개수 증가

### 레이저 ⚡
- 관통하는 레이저 빔
- 직선상의 모든 적 관통
- 업그레이드: 폭과 길이 증가

### 도끼 🪓
- 플레이어 주위를 회전하는 도끼
- 지속적인 근접 방어
- 업그레이드: 도끼 개수 증가, 궤도 반경 증가

## 🎁 패시브 아이템

### 방어구 🛡️
- 받는 피해 감소 (최대 50%)
- 레벨당 5% 피해 감소

### 날개 🪽
- 이동 속도 증가
- 레벨당 0.3 속도 증가

### 시금치 🥬
- 모든 무기의 공격력 증가
- 레벨당 15% 데미지 증가

### 클로버 🍀
- 크리티컬 확률 증가 (최대 50%)
- 레벨당 8% 확률 증가

### 왕관 👑
- 경험치 획득량 증가
- 레벨당 10% 경험치 배율 증가

### 자석 🧲
- 경험치 습득 범위 증가
- 레벨당 20 범위 증가

## 👾 적 종류

### 일반 몬스터 🟢
- 균형잡힌 속도와 체력
- 기본 경험치 획득
- 초반부터 등장

### 빠른 몬스터 🟡
- 빠른 속도로 추격
- 낮은 체력
- 높은 경험치
- 초반부터 등장

### 탱크 몬스터 🔴
- 느린 속도
- 높은 체력과 공격력
- 매우 높은 경험치
- 초반부터 등장

### 사수 몬스터 🎯
- 원거리 투사체 발사
- 플레이어와 거리 유지
- 중간 난이도부터 등장 (10초 후)

### 폭발 몬스터 💥
- 죽을 때 폭발하여 주변 피해
- 플레이어와 다른 적 모두 피해
- 맥동 효과로 식별 가능
- 중간 난이도부터 등장 (10초 후)

### 분열 몬스터 💜
- 죽을 때 3마리의 작은 몬스터로 분열
- 보라색으로 식별 가능
- 높은 경험치
- 중간 난이도부터 등장 (15초 후)

### 힐러 몬스터 💚
- 주변 적들을 주기적으로 치유
- 초록색 십자가 표시
- 우선 제거 대상
- 높은 난이도부터 등장 (20초 후)

### 텔레포터 몬스터 ✨
- 주기적으로 플레이어 근처로 순간이동
- 반짝이는 효과로 식별
- 예측하기 어려운 움직임
- 높은 난이도부터 등장 (20초 후)

### 보스 몬스터 👑
- 매우 크고 강력함 (HP 100)
- 붉은 광채와 왕관 표시
- 60초마다 등장
- 처치 시 대량의 경험치 (50 XP)

## 🎯 게임 시스템

### 레벨업
- 경험치를 모아 레벨업
- 레벨업 시 3가지 옵션 중 선택
- 새로운 무기 획득 또는 기존 무기/아이템 강화

### 난이도 증가
- 시간이 지날수록 적 스폰 속도 증가
- 다양한 적 조합으로 도전 난이도 상승

### 빌드 전략
- **공격형**: 시금치 + 여러 무기 조합으로 높은 DPS
- **생존형**: 방어구 + 체력 재생 + 날개로 장기 생존
- **경험치형**: 왕관 + 자석으로 빠른 레벨업
- **균형형**: 모든 요소를 골고루 강화

## 📊 UI 정보

화면 왼쪽 상단에서 확인 가능:
- **HP**: 현재 체력 / 최대 체력
- **XP**: 현재 경험치 / 다음 레벨까지 필요 경험치
- **레벨**: 현재 레벨
- **시간**: 생존 시간
- **처치**: 처치한 적의 수

## 🎮 게임 팁

### 기본 전략
1. **초반**: 마법 미사일을 강화하여 안정적인 공격력 확보
2. **중반**: 새로운 무기 획득으로 다양한 상황 대처
3. **후반**: 생존 아이템(방어구, 체력 재생) 강화로 장기전 준비
4. **경험치**: 자석 아이템으로 이동 없이 경험치 습득

### 무기 조합
5. **근접 방어**: 마늘 오라 + 도끼 = 강력한 근접 방어
6. **광역 제거**: 레이저 + 번개 = 효율적인 광역 제거
7. **군중 제어**: 성수 + 화염구 = 범위 피해 극대화

### 적 대응 전략
8. **힐러 우선**: 힐러 몬스터는 최우선 제거 대상 (다른 적을 치유함)
9. **폭발 주의**: 폭발 몬스터는 거리를 두고 처리 (폭발 피해 주의)
10. **사수 회피**: 원거리 투사체를 발사하는 사수는 측면 이동으로 회피
11. **텔레포터 대비**: 순간이동하는 적은 항상 주변 경계
12. **보스 준비**: 60초마다 보스 등장 - 체력과 무기 준비 필수
